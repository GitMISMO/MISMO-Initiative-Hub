Facilitator key helper

Makes a passcode and the hash that goes in facilitators.json. Nothing leaves this page.

1. Who is this key for?

Their display name, exactly as they'll type it when they save. It becomes the author on their commits, so use a real name.

2. Passcode

Generate one. Don't make one up: the hash is public, and only a random passcode stays safe once its hash can be seen.

Resetting someone's passcode? Generate a new one and replace their hash. The old passcode stops working the moment the file is committed.

3. Paste into facilitators.json

For a facilitator, add this object to the facilitators array.

{ "name": "", "hash": "" }
Admin key: keep a copy of the passcode in a password manager. Facilitators' passcodes can be regenerated from the admin panel; yours can only be reset by editing the file directly.
